## Composition rules for this family

Keep an eyebrow/topic label, a prominent heading, the action or main information, an explanatory diagram, a short useful note, and unobtrusive branding/page tracking when the content supports those roles. Use the actual content to decide the sequence and number of regions.

The 1080 × 1350 examples use roughly 72 px side margins, 22–40 px gaps between major regions, 69–89 px Thai headings, 28–31 px explanatory text, and 22–25 px notes. These are useful starting proportions, not universal limits. Dense pages need intentional regrouping rather than uniform font reduction.

The 1920 × 1080 examples use roughly 80 px side margins, a 64 px column gap, 80–88 px Thai detail headings, and 31 px supporting text. Headers and page tracking span the width; titles and actions occupy the left column, with diagrams and notes on the right. Cover and ending layouts follow the same horizontal hierarchy with content-specific sizing. These values are starting proportions for the approved examples; adapt them to new content.

Style 1 keeps large display text and dark diagram cards in landscape. Style 2 places its oversized cover numeral beside the title and uses a clean overview on the right. Style 3 keeps bilingual editorial headings on the left and mint/white diagram groupings on the right. All three preserve the original information while using the wider canvas.

Keep style 1's display emphasis and dark cards. Keep style 2's clean black/white hierarchy and purple markers. Keep style 3's bilingual editorial hierarchy and mint groupings. A background recolor alone does not implement a new numbered style.

Use Noto Sans Thai for Thai, including text inside diagrams. Use one clear graphic treatment within each style. In style 3, English editorial lines can wrap when new content is longer than the approved examples; the example's `white-space: nowrap` must be adapted if it causes clipping.

The examples have seven-page progress indicators and NEXTO branding. Replace these with the real count and intended brand for each new assignment.
